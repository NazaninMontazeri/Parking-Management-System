## ✨ ویژگی‌ها

### عملکردهای اصلی
- 🚗 **ثبت ورود خودرو:** دریافت اطلاعات خودرو (نام، رنگ، پلاک و زمان ورود) و افزودن آن به لیست پارکینگ.
- 🚫 **جلوگیری از ثبت تکراری:** بررسی خودکار پلاک خودرو برای جلوگیری از ثبت دوباره یک خودرو در پارکینگ.
- 📋 **نمایش لیست پارکینگ:** مشاهده لیست تمام خودروهای موجود در پارکینگ به همراه اطلاعات آن‌ها.
- 🔍 **جستجو بر اساس پلاک:** پیدا کردن سریع اطلاعات یک خودرو با وارد کردن شماره پلاک آن.
- 🚪 **خروج از برنامه:** بستن ایمن برنامه از طریق منو.

### رابط کاربری
- 💻 **رابط کاربری کنسولی (CLI):** منوی متنی ساده و خوانا برای تعامل با کاربر.
- ⚠️ **مدیریت خطا:** نمایش پیام‌های مناسب در صورت تکراری بودن پلاک، پیدا نشدن خودرو یا وارد کردن گزینه نامعتبر.

## 🏗️ معماری

این پروژه با استفاده از الگوی جداسازی منطق (Separation of Concerns) نوشته شده است تا کدها خوانا و قابل نگهداری باشند:

```text
┌─────────────┐
│   main.py   │  لایه رابط کاربری (منو و تعامل با کاربر)
└──────┬──────┘
       │
       ↓
┌─────────────────────┐
│ parking_module.py   │  لایه منطق کسب و کار (توابع پردازش داده‌ها)
└──────┬──────────────┘
       │
       ↓
┌─────────────┐
│  Data List  │  لایه ذخیره‌سازی (لیست در حافظه)
└─────────────┘
